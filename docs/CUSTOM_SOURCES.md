# 自定义音源配置

入口：设置 → 存储与账户 → 音源配置。

仅内置网易云官方接口。用户最多自行添加 7 个可信的 HTTPS 解析接口，新增默认关闭，可独立启停、编辑、删除并上下排序。补源总开关关闭时不会调用自定义服务。

播放优先请求官方完整音频，然后按顺序尝试已启用服务；无效时继续后续服务。官方账号权限不因配置自定义服务而改变。不要连接无权使用的内容服务。

## 自定义解析服务协议

仅接受 HTTPS GET 服务地址（不是音乐平台主页，不执行脚本），请求查询参数：

| 参数 | 内容 |
| --- | --- |
| id | 网易云歌曲 ID |
| name | 歌曲名称 |
| artist | 歌手名称 |
| album | 专辑名称 |
| durationMs | 时长毫秒 |

服务返回 JSON：

```json
{"url":"https://your-authorized-service.example/audio.mp3","headers":{}}
```

`url` 必须是可播放的 HTTPS 完整音频链接；`headers` 可选，为音频请求附加的字符串头。无可用内容时返回 `{"url":null}` 或非成功状态。现有任意平台 API 不一定直接符合此协议，需要用户自行提供适配服务。

歌曲元数据会发送给用户配置的服务，但不会自动附带网易云 Cookie、密码或登录令牌。请仅配置可信服务。


配置仅保存在用户本机；不发送网易云登录 Cookie。服务会收到歌曲查询元数据。自定义地址和请求头可能含敏感信息，请勿公开提交。当前不支持任意脚本、平台主页解析或无协议约定的自动导入。
